# Transport

منصة مستقلة لطلب مركبات النقل والمعدات والخدمات المنزلية.

## الواجهات
- User: خفيف / ثقيل / للمنزل، نقطة الالتقاء والوجهة والتتبع.
- Captain: الطلبات المناسبة، السعر قبل القبول، الملاحة وحالات التنفيذ.
- Admin: لوحة ويب لإدارة التشغيل والكباتن والأسعار والطلبات.

## التصنيفات
- خفيف: أنواع البيك أب.
- ثقيل: دينا، سطحة، تريلة.
- للمنزل: غاز، ماء حلو، وايت ماء صغير/متوسط/كبير.

## تشغيل
```bash
npm start
```
