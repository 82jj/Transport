# واصل — تسجيل الكباتن واعتماد الخدمات

نموذج التسجيل يشمل الجوال والبريد وكلمة المرور وتأكيدها؛ الاسم الرباعي والهوية/الإقامة؛ نوع المركبة والموديل والسنة ورقم الهيكل؛ سريان الرخصة والاستمارة والتأمين ومرفقاتها؛ صور داخلية وخارجية؛ فئات خفيف/ثقيل/منزلي؛ وإقرار مؤرخ بإصدار الشروط.

إنشاء الحساب يحفظ مسودة فقط. لا يظهر طلب المراجعة للإدارة حتى اكتمال المرفقات والموافقة على الإقرار والإرسال. يمكن إكمال المسودة أو تصحيح الطلب المرفوض وإعادة إرساله. طلب قيد المراجعة مقفل؛ كل قرار مربوط بإصدار الطلب وسجل سابق. القبول يصدر اسم مستخدم ويربطه بالجوال والبريد. لا تعرض كلمات المرور للإدارة ولا ترسل في الرسائل.

## التخزين والصلاحيات

المرفقات وبيانات الطلب الحساسة مشفرة AES-256-GCM في SQLite على Volume الدائم، وليست في المستودع أو ملفات الواجهة. مؤشرات البحث للجوال والهوية تستخدم HMAC. الحساب المالك والإدارة وحدهما يستطيعان قراءة المرفقات. ملفات الصور JPEG/PNG/WebP؛ PDF للمستندات فقط؛ 4 MiB للملف، 5 صور لكل جهة، 40 MiB مخزنة للحساب. هذا تحقق بنيوي وليس فحص برمجيات خبيثة أو توثيقًا حكوميًا.

`CAPTAIN_DATA_KEY` سر ثابت لا يقل عن 32 حرفًا، في خدمة API فقط. يجب ضبطه قبل نشر هذا التحديث. لا تغيره دون إعادة تشفير ونسخة احتياطية. فقدانه يمنع قراءة الطلبات والمرفقات. لا تغييرات مدمرة على الجداول القديمة.

الحساب القديم غير المكتمل لا يتلقى عروضًا جديدة حتى إكمال التسجيل واعتماد الفئات. الرحلات المسندة تبقى مرئية. القبول لا يجعل الكابتن متصلًا تلقائيًا. إيقاف الاتصال يمنع العروض والقبول المباشر ويبقي الرحلة الجارية. تجديد الحضور كل 45 ثانية ومهلة 120 ثانية عند غيابه؛ heartbeat لا يعيد تشغيل حساب أغلق يدويًا. انتهاء أي وثيقة يوقف العروض. التصفية حسب الفئات المعتمدة فقط؛ GPS والإسناد الجغرافي غير موصولين.

## الرسائل

قرار المراجعة ورسالتا النتيجة يسجلان في معاملة واحدة. عند القبول تتضمن الرسالة اسم المستخدم والخدمات؛ وعند الرفض السبب. يدعم Outbox إعادة محاولة محدودة لـ429 ويمنع تكرار القرارات. البريد يستخدم Resend مع Idempotency-Key، وSMS يستخدم Unifonic مع CorrelationID. نتيجة إرسال غير مؤكدة لا تعاد تلقائيًا منعًا للتكرار. الحالة accepted تعني قبول المزود، وليست إثبات التسليم؛ webhooks التسليم ليست ضمن هذه النسخة.

متغيرات API: `UNIFONIC_APPSID`, `UNIFONIC_SENDER_ID`, `RESEND_API_KEY`, `EMAIL_FROM`. بدونها تعرض الإدارة blocked/مزود غير مهيأ؛ لا يُدعى إرسال فعلي. ضع المفاتيح في أسرار الاستضافة فقط. لا تُنسخ مفاتيح مشاريع أخرى. عند تفعيل المزود تُرسل القرارات الحالية المنتظرة؛ راجع سجلها أولًا.

الحقول مرتبطة بالحساب لكن ملكية الجوال والبريد لم توثق بـOTP. الشروط إقرار تشغيلي أولي يحتاج سياسة قانونية قبل التشغيل التجاري. مسافة وتسعير المشوار تجريبيان؛ لا دفع أو GPS أو محادثة في هذا التعديل.

## الاختبار

HTTP + SQLite مؤقتة: التحقق من الحقول والمرفقات والحماية والتشفير، القبول/الرفض والسبب، إعادة التقديم والتضارب، الدخول بالجوال والبريد واسم المستخدم، الفئات والاتصال واستمرار الرحلة أثناء إغلاق استقبال الطلبات. متصفح Chromium وWebKit يختبران التسجيل والرفع والمراجعة وطلب المشوار الفعلي ببيئة مؤقتة. لا تنشأ بيانات اختبار في الإنتاج.
