# واصل — الخرائط والتتبع

## النسخة الحالية

خريطة تفاعلية حقيقية من OpenStreetMap عبر Leaflet1.9.4. البحث بالعربية من فهرس OSM خاص في transport-maps، والمسار والمسافة والزمن من OSRM الخاص، لا من خادم تجريبي عام. تاريخ بيانات المحرك2026-09-01؛ العرض من مربعات OSM. قد لا تشمل البيانات جميع العناوين والمداخل.

تحديد الالتقاء يدويًا أو بإذن تحديد الموقع، والبحث عن الوجهة أو تحديدها على الخريطة. اقتراح أقرب نقطة طريق ضمن250م يحتاج تأكيد المستخدم. لا يضمن دخول المركبة للعقار؛ يجب مراجعة المدخل الفعلي. المسافة الجديدة محسوبة بالخادم من الطريق.

عند قبول الرحلة يُطلب إذن الموقع ويمكن للكابتن المشاركة مع صاحب الطلب. يتغير هدف المسار من الالتقاء إلى الوجهة عند بدء النقل. إيقاف المشاركة أو تسجيل الخروج أو إنهاء الرحلة يمسح أحدث إحداثية ويوقف المشاركة. آخر قراءة مشفرة فقط، دون سجل تحركات، ولا يقرأها زائر أو مستخدم آخر.

## الحدود

تتبع المتصفح في المقدمة فقط مع إذن الموقع. لا ضمان بالخلفية أو عند قفل الشاشة. لا يُعدّل وقت القراءة القديمة لتبدو حديثة. المسار لسيارات عامة وليس معتمدًا للشاحنات أو الحمولات الخطرة؛ راجع قيود الوزن والارتفاع والمدخل. الزمن تقديري بلا زحام حي. ترتيب الطلبات حسب أقرب كابتن لم يُفعّل. التسعير تجريبي والدفع غير مفعل.

## حالة Google

### وضع المفتاح التجريبي

طلب المالك استخدام مفتاح Maps Demo Key للتجربة. `MAPS_PROVIDER=google-demo` يستخدم `GOOGLE_MAPS_BROWSER_KEY` المخصص للتجربة في عرض الخريطة وطلبات Places وRoutes وGeocoding v4. لا يقرأ هذا الوضع مفتاح الخادم `GOOGLE_MAPS_API_KEY` ولا ينسخه إلى المتصفح. يظل وضع `google` العادي يشترط مفتاحين مستقلين.

تعرض واجهتا المستخدم والكابتن `Google (تجريبي)`؛ للمفتاح حصة استخدام محدودة، ونفادها يعرض رسالة واضحة دون التحول إلى مزود آخر. المفتاح تجريبي وليس تفعيلًا لحساب Google مدفوع أو إعدادًا للإطلاق التجاري. عند الانتقال للإطلاق يلزم إعداد الفوترة والمفاتيح المقيدة وتغيير الوضع إلى `google`.

### وضع الإنتاج

`MAPS_PROVIDER=google` يبدّل العرض والبحث وحساب الطريق إلى Google معًا. الافتراضي `osm` حتى اكتمال إعداد المفاتيح وفحص العرض الحقيقي.

في خدمة API `transport-web`:
- `GOOGLE_MAPS_API_KEY`: مفتاح الخادم الموجود؛ يبقى سريًا. يلزم Places API (New)، Routes API وGeocoding API.
- `GOOGLE_MAPS_BROWSER_KEY`: مفتاح مستقل للمتصفح؛ يُرسل علنًا في maps/config. يجب تقييده بـMaps JavaScript API وبالموقعين:
  - `https://transport-user-isolated-production.up.railway.app/*`
  - `https://transport-captain-isolated-production.up.railway.app/*`
- لا تُنسخ قيمة مفتاح الخادم إلى متغير المتصفح. التطبيق يرفض مفتاحين متطابقين أو إعداد Google ناقصًا.
- لا تفعّل `MAPS_PROVIDER=google` قبل نشر تغييرات API والمستخدم والكابتن وفحص صلاحية الخدمات. المتغيرات منفصلة عن المستودع.

بحث Places يستخدم جلسة واحدة للاقتراحات وتفاصيل المكان المختار. العناوين بالعربية ومقيّدة بالسعودية. عند تحريك الدبوس يُجلب العنوان دون نقل المدخل المختار. حساب الطريق دون زحام حي، وليس توجيهًا معتمدًا للشاحنات. تبقى أحدث إحداثية الكابتن مشفرة ومقيدة بالرحلة.

فشل Google يعرض خطأ ولا يتحول بصمت إلى OSM. لا تُخزّن هندسة Google Routes داخل سجل الطلب؛ تُحسب عند عرض الرحلة الجارية. اختبارات SDK المعزولة تختبر عقد الربط فقط، ولا تثبت تحميل خريطة Google الحقيقية. يلزم فحص حي بمفتاح المتصفح المقيد قبل إعلان تفعيل Google.

### الفحص السابق

المفتاح الذي وفره المالك محفوظ في أسرار API فقط وليس المستودع أو المتصفح. فحص Routes API وPlaces API(New) نجح. Roads API أعاد API_KEY_SERVICE_BLOCKED، وMap Tiles API أعاد SERVICE_DISABLED. لم يُنشر Google Maps، ولا تُعرض بيانات Google Routes/Places على خريطةOSM. لم نكشف مفتاح الخادم كبديل لمفتاح متصفح.

لانتقال Google: يلزم مفتاح متصفح منفصل مقيد بالنطاقين لـMaps JavaScript API، أو تفعيل Map Tiles API ثم ربط عرضه الآمن. لا يكفي عمل Routes/Places وحدهما. إدارة خدمات ومفاتيح حسابGoogle ليست متاحة باتصالRailway/GitHub. المزود الفعلي الحالي OpenStreetMap معلن في الواجهة.

## التشغيل والتحقق

MAPS_ORIGIN=http://${{transport-maps.RAILWAY_PRIVATE_DOMAIN}}:${{transport-maps.PORT}} في API الحالي. حافظ على CAPTAIN_DATA_KEY وحجم/data. helper بلا نطاق عام أو بيانات حسابات. التطبيقات منفصلة.

الاختبارات تستخدم SQLite وحسابات وGPS معزولة. قراءة WebKit التجريبية تُجدّد قبل القبول بعد طول التسجيل؛ يظل الخادم يرفض القراءات القديمة. الفحص الحي يتحقق من ملفات التطبيقات، والعربية والطريق والعرض الحقيقي دون حسابات أو طلبات أو GPS تجريبي في الإنتاج.
